# 寻迹 · 产品设计案例网站

XUNJI 是一款本地优先的收纳 App，帮你记住有什么、放在哪、什么时候到期。这个仓库是它的设计案例展示网站，一个纯静态单页站点，默认英文，可切换中文。

## 页面内容

- **Hero / App 展示**：四屏界面（记录、查找、提醒、适配）与手机模型
- **设计取舍**：本地优先、到期提醒、单一绿色强调色、可安装的 PWA
- **设计过程**：用户画像、亲和图、用户旅程、情绪曲线、洞察到功能的对照
- **可用性测试**：6 人测试统计、用户基线、障碍比例图表、2.0 与 3.0 界面对比

数据来自《寻迹APP用户体验测试表》和《寻迹APP用户体验测试汇报》。测试于 2026-11-22 完成，汇报人：易千惠、张婉清、丁紫妍。

App 本体：https://ananpaofu.github.io/new-shouna-app/

## 本地预览

直接用浏览器打开 `index.html` 即可，无需构建或安装依赖。若希望模拟线上环境，可在目录内启动任意静态服务器，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 文件结构

```
.
├── index.html    # 页面结构与全部文案节点
├── styles.css    # 全部样式（深色画廊风格、响应式）
├── script.js     # 中英切换、滚动显现、导航高亮
└── README.md     # 本文件
```

## 部署到 GitHub Pages

1. 新建公开仓库，例如 `xunji-case`。
2. 把本目录下的 `index.html`、`styles.css`、`script.js`、`README.md` 上传到仓库根目录。
3. 进入仓库 **Settings → Pages**，Source 选择 `main` 分支 / `root`，保存。
4. 等待 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

站点为纯前端，无后端、无构建步骤。语言选择会保存在浏览器本地存储中，首次访问默认英文。
